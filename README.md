# 文明6 机制重构 Mod（civ6mod）

将《文明6》从"棋盘策略"升级为"大地图模拟"：更精细的地形尺度、以人为本的单位系统、网络效应驱动的经济、多层次的战争外交。

## 设计原则

1. **模拟优先**——机制应让游戏更像"文明发展模拟器"而非抽象棋盘游戏
2. **以人为本**——操作重心从"地块管理"转向"单位/人物管理"，单位可自动化
3. **信息可视化**——复杂机制必须有清晰的游戏内反馈，不能藏在黑箱中
4. **AI 可玩**——所有新机制必须能被 AI 理解并使用
5. **向后兼容**——保留官方文明的核心玩法身份
6. **自建数值体系**——参考官方但不拘泥于官方数值，相对平衡优先于绝对对标
