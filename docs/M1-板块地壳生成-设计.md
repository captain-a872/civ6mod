## 1. 目标与非目标

### 1.1 目标

1. 海陆分布由板块类型（陆壳/洋壳）+ 板块边界相互作用推导，而非分形阈值切割。
2. 山系（山地/主脊）的位置、走向、长度完全由消亡边界决定，呈链状。
3. 板块内部（尤其泛大陆级陆块内部）是大片连续低地，从生成机制上保证"平原存在"。
4. 生长边界在洋盆内形成浅水海岭链，在近岸形成大陆架过渡。
5. 海拔场 `g_RR_elevation` 与形态层 `g_RR_form` 的**对外契约完全不变**——下游已验收逻辑（M2 河系分级/河面、M2.5 微地貌、M3 矩阵地形、M6 海洋分级、M8 河流命名、artdef 借壳）一行不改，只改它们消费的地基数据。
6. 新增数据层（板块号/边界类型/火山标记）落盘为全局表，供后续资源地质亲和（策划案 4.2 地质资源层）与灾害标签（策划案 7.1 地震/火山）消费。

### 1.2 非目标（本轮明确不做）

- 气候与降水（M2）：雨影、季风、距海衰减全部后置，本文只留接口（§7）。
- 河流/湖泊/微地貌/资源的具体分布：沿用已验收逻辑，仅其输入（海拔/形态）换源。
- 地球物理真实模拟：策划案核心原则是"轻量因果"——板块不做速度场、不做旋转、不做造山过程模拟，只做"一次成型"的因果赋值。
- 板块随时间演化（游戏内地质事件）：灾害章接口预留，本轮不实现。

## 2. 总体管线

```
① 板块种子布局（8~10 张，类型配比见 §3.1）
        ↓
② Voronoi 归属（含噪声抖动 → 自然海岸线，§3.2）
        ↓
③ 边界格检测 + 板块对边界类型 roll（§4）
        ↓
④ 地貌映射 → 海拔场 + plotTypes（§5）
        ↓
⑤ 形态层分类（复用 RR_ClassifyForm，阈值沿用 M8 调参值）
        ↓
⑥ 探针打印（§8，供 tuner 日志对照预期表）
```

与 `RR_Continents.lua` 的对接点：

| 阶段 | 原版行为 | 本轮行为 |
|------|---------|---------|
| `GeneratePlotTypes` | 分形海陆 + Shift + 中央裂谷 + 最大陆块拒绝循环 + ApplyTectonics + AddLonelyMountains | 整体替换为 `RR_Tectonics_GeneratePlots(world_age)` 一次调用 |
| `GenerateTerrainTypes` + `ApplyBaseTerrain` | 按 plotTypes 赋地形壳（含纬度带） | **不动**（"气候先纬度"的 v1 近似正好由它提供） |

| `GenerateMap` 中"海拔/形态层"阶段 | `RR_BuildElevationAndForms`（分形派生） | 改为 `RR_Tectonics_BuildForms()`（板块派生，契约同） |
| 下游全部（河流/湖/分级/微地貌/矩阵/特征/资源/出生点） | — | **不动** |

## 3. 板块多边形生成算法

### 3.1 板块种子布局（参照现实地理的配比）

在 168×108 网格（1:4 标准图）上撒 **9** 张板块种子（常量 `RR_TEC_PLATE_COUNT`，可调 8~10）：

| 板块 | 数量 | 地壳类型 | 现实参照 |
|------|:----:|---------|---------|
| 泛大陆级 | 1 | continental（major） | 联合古陆/欧亚级体量的大陆核心 |
| 中陆块 | 2 | continental | 北美/非洲级陆块 |
| 大洋板块 | 6 | oceanic | 太平洋式洋盆 |
| 小块（散落） | 由种子随机位置自然形成（小块边界占比高，形态接近微板块/岛弧） | 随 roll | 菲律宾海/加勒比式小块 |

种子位置用 `TerrainBuilder.GetRandomNumber`（地图种子驱动，确定性可复现）。两极缓冲带（`y ≤ H/13` 与对称上缘，沿用原版不变量）不参与种子落地与陆地生成，强制海洋——保证极地冰海与纬度气候带成立。

陆海比由陆壳种子占比决定：3/9 张陆壳 ≈ 33% 陆地（Voronoi 面积近似均分 + 抖动再分配），叠加缓冲带与边界侵蚀后落在 **35%~42%** 区间，与原版 normal 海平面（陆 38%）观感一致。**原版 sea_level 配置项自此失效**（没有"海平面升降"概念，陆海比由板块配比管），代码注释中诚实标注。

### 3.2 Voronoi 归属与海岸线抖动

每格归属"加权距离"最近的种子：

```
score(x,y;p) = toroidal_dx² + dy² + JITTER · (noise(x,y) − 0.5) · L²
```

- `toroidal_dx`：x 方向环向回绕距离（`min(|dx|, W−|dx|)`），保证板块横跨地图东西接缝时连续。
- `noise(x,y)`：**确定性网格噪声**——固定顺序预生成的一次性随机表（`TerrainBuilder.GetRandomNumber` 单次遍历产出），不用 `os.time`/数学 hash，保证同种子全链路可复现（沿用调研 A 报告 4.5 结论：随机调用顺序固定即可复现）。
- `JITTER`（常量 0.35，相对 `L = W/12` 归一）：把 Voronoi 的直线边界打散成曲折海岸线。这是"海岸破碎度"的最小实现（策划案 1.1 第 1 步中"海岸破碎度"一词的落点）。
- y 方向不回绕（极地强制海洋，§3.1）。

取舍说明：考虑过"随机游走扩张"（从种子沿邻格随机扩张至满图）作为 Voronoi 的替代——它边界更自然，但 (a) 扩张顺序敏感、调参不可控；(b) 每格到种子距离不可查，后续"距板块边界距离"（陆棚/山裙带都要用）需另建 BFS。Voronoi + 噪声抖动用一份距离数据同时服务归属、边界检测与带宽计算，选它。

## 4. 边界类型判定（相邻板块相对运动）

### 4.1 板块对 roll

每个**无序板块对**（边界两侧实际相邻者）roll 一次相对运动类型，全图一致（同一条边界不会中途从消亡变成生长——否则山链断成海岭，违背因果直觉）：

| 类型 | 概率 | 常量 | 现实参照 |
|------|:----:|------|---------|
| 消亡（convergent） | 45% | `RR_TEC_P_CONVERGENT = 45` | 陆陆碰撞 / 洋陆俯冲 |
| 生长（divergent） | 30% | `RR_TEC_P_DIVERGENT = 30` | 洋中脊 / 大陆裂谷 |
| 转换（transform） | 25% | `RR_TEC_P_TRANSFORM = 25` | 圣安德烈斯式走滑 |

roll 使用同一随机流（确定性）。已知粗糙处：真实边界会分段转变类型（如太平洋板块边界北段生长、东段消亡），v1 按板块对一刀切，v2 可改为"边界段 roll"（§9）。

### 4.2 边界格与消亡细分

- **边界格**：任一六邻格归属不同板块即边界格；记本格所见边界类型（多对并存时按 消亡 > 生长 > 转换 优先级取主导——消亡最造地形）。
- **消亡细分**不需额外随机，由两板块地壳类型决定：
  - 陆 × 陆 → **造山带**（喜马拉雅型）：边界行 + 两侧各 1~2 格山系链（§5.2）。
  - 洋 × 陆 → **俯冲带**（安第斯/海沟型）：洋侧海沟（最深水），陆侧海岸山链 + 火山弧。
- 陆 × 洋的生长边界（陆地张裂入洋）按海岭浅水 + 陆侧裂谷低地处理（§5.3）。

## 5. 地貌映射与海拔模型

### 5.1 海拔总表（米，连续值）

| 地貌 | 海拔公式（u/d 为 0~1 噪声） | plotTypes | 形态层归类 |
|------|---------------------------|-----------|-----------|
| 洋盆内部 | −2500 − 2500·d（−2500~−5000） | OCEAN | 深海/浅海（按阈值） |
| 海岭链（生长·洋内） | −600 + 450·u（−600~−150） | OCEAN | **浅海链**（>−800 恒浅海） |
| 大陆架（陆块向洋 2~4 格） | −100 − 250·u | OCEAN | 浅海 |
| 陆块内部（地壳平原） | 20 + 130·u（20~150） | LAND | **低地**（大片连续） |
| 地盾（陆块内部 0~2 处随机古核） | 150 + 200·u | LAND（局部 HILLS） | 低地/隆起 |
| 裂谷（生长·陆内） | 10 + 60·u | LAND | 低地 |
| 造山带（消亡·陆陆） | 1500 + 1200·u；链核 ≥2800 + 700·u | **MOUNTAIN** | 山地/**主脊** |
| 俯冲带陆侧（消亡·海陆） | 700 + 800·u | MOUNTAIN | 山地 |
| 海沟（消亡·海陆，洋侧） | −4500 − 800·d | OCEAN | 深海 |
| 转换边界 | 陆 30+100·u / 洋 −2000−2000·d | 同宿主 | 不改变形态（探针计数） |
| 热点（陆） | 600 + 600·u | HILLS（隆起宿主） | 山地（+火山标记） |
| 热点（洋） | 300 + 500·u | **LAND**（1 格火山岛） | 山地/隆起（+火山标记） |

形态分类阈值**沿用 M8 用户调参值**（深海 ≤ −800 / 浅海 ≤ −100 / 山麓 200~700 / 山地 700~2800 / 主脊 > 2800），不重新发明——`RR_ClassifyForm` 函数本体不动，只换输入。

### 5.2 山系链规则（R4 的核心落地）

- **山脉 plotTypes 只落在消亡边界格**：陆陆消亡的边界行全行 MOUNTAIN，两侧各 1~2 环 HILLS 裙边（山麓带另有 `RR_ApplyFoothills` 在落地阶段补一格子宽裙边，二者叠加不冲突）。
- 链内"核心"（自身是山且 ≥3 个山邻格）抬升 >2800 m 进主脊带——成链的主脊段由此出现，雪线换肤（`RR_ApplySnowRidge`）照常消费。
- 陆海消亡的海岸山链宽度减半（一格山 + 一格裙边），避免海岸全是山。
- **原版 `ApplyTectonics`/`AddLonelyMountains` 不再调用**——孤立山与分形山脊正是"山河占绝大部分陆地"（用户实测）与"山不成链"的成因。

### 5.3 大陆架与海岭链

- 陆棚：从陆壳格向外做 2~4 环膨胀（BFS 距离），途经洋壳格抬升到 −100~−350 m——保证任何海岸线外有一圈浅海，而不是悬崖式深海。
- 海岭链：生长边界在洋内的格直接赋 −600~−150 m，形态恒浅海；链两侧格不受影响（仍深海），浅海链因此在深蓝洋盆中肉眼成线。
- 海陆交界的生长边界：洋侧同海岭，陆侧按裂谷低地（张裂海岸，现实参照东非/红海发育早期）。

### 5.4 板内低地保证（R4 的第二半）

陆块内部**不加任何随机山丘**（`AddTerrainFromContinents` 旁路，§6.2）；内部起伏只来自：
- 地盾：每块陆板 0~2 个随机古核，平缓隆起 150~350 m（非洲/加拿大地盾式）；
- 邻格高差 ≥50 m 时形态判"隆起"（岗地），这是低地内部的轻起伏，不是山。

目标：低地+隆起占陆地 **≥70%**（对照 M8 调参目标 60%——M8 是在分形山上贴补丁，本轮从机制上超额完成，探针对照见 §8）。

### 5.5 热点火山

- 数量 2~4 个（常量 `RR_TEC_HOTSPOTS = 3` ±1 roll），位置随机（避开极地与消亡边界格）。
- 落点为陆块内部 → 该格 HILLS + 海拔 600~1200 m + **火山标记**；落点为洋盆 → 该格改 LAND（1 格火山岛）+ 标记。
- 火山标记存 `g_RR_volcano`（1-based 布尔表）。本轮不放置原版火山特征（火山特征生成器在 GS 下由特征阶段统一处理，且策划案火山卡是"山地/主脊宿主"——先标数据，特征化归灾害章）。

## 6. 与原有系统的关系

### 6.1 三层模型接口（契约不变清单）

| 数据 | 类型 | 消费者（不动） | 本轮变化 |
|------|------|--------------|---------|
| `g_RR_elevation` | 全局表 [y·W+x+1] = 米（float） | M2 河系分级（<300 m 转水面判据）、M6 海洋分级、持久化、抽样探针 | 换源：板块派生（原：分形派生） |
| `g_RR_form` | 全局表 [y·W+x+1] = 8 类形态名 | M2 漫滩/三角洲宿主判定、M3 矩阵地形、M8 雪线 | 换源（同上） |
| `g_RR_plateId` | 全局表 = 板块号 1..N（**新增**） | 暂无（M2 后资源/灾害消费） | 新增 |
| `g_RR_boundaryType` | 全局表 = 0 板内 / 1 消亡 / 2 生长 / 3 转换（**新增**） | 暂无（灾害地震带/地质亲和） | 新增 |
| `g_RR_volcano` | 全局表 = true 即热点火山（**新增**） | 暂无（灾害火山卡） | 新增 |

`g_RR_elevation`/`g_RR_form` 由 `RR_Continents.lua` 的 local 提升为**全局**（跨文件契约的唯一改动；两文件同 Lua 状态，include 顺序保证可见）。

### 6.2 原版分形处置：**完全旁路**（R6 的取舍）

不调用：`InitFractal`、`ShiftPlotTypes`、`GenerateCenterRift`、最大陆块拒绝循环、`ApplyTectonics`、`AddLonelyMountains`、`AddTerrainFromContinents`。

理由：
1. **分形海陆正是被替换对象**——"降级为细节起伏修饰"意味着同时维护两套地基生成器，任何一处阈值漂移都会造成"海陆与海拔不一致"的隐性 bug（M1~M8 实际吃过的亏）。
2. 原版分形消耗引擎随机流（`Fractal.Create` 系列），保留它会让"板块+分形"的随机顺序纠缠，同种子复现排查变难。
3. 细节起伏由 §3.2 的确定性网格噪声提供——幅度可控、有探针、可单独调参。
4. `AddTerrainFromContinents` 按 world_age 在陆内随机撒丘陵，与"板内大片低地"（R4）直接冲突，必须旁路；world_age 配置项自此只影响地形壳的纬度带细节，注释中标注。

保留不动：`GenerateTerrainTypes`（纬度带地形壳——"气候先纬度"基调的免费 v1 近似）、`ApplyBaseTerrain`、`AreaBuilder.Recalculate`/`AnalyzeChokepoints`/`StampContinents`、河流/湖泊/特征/资源/出生点全链。

### 6.3 下游已验收逻辑保护清单（回归时逐项核对）

- M2 河系分级/河面转化/急流/漫滩/三角洲：消费海拔与形态 → 数据源换但契约同，预期大河从消亡边界山链发源（比旧版"山随机分布"更符合策划案 8.4"河流追溯到山地水源"）。
- M2.5 Layer3 微地貌（绿洲/沼泽直放）：读地形 ID，不动。
- M3 矩阵地形 14 卡：读形态表，不动。
- M6 海洋分级阈值（深海 ≤−800 / 浅海 ≤−100）：海岭链与陆棚天然落浅海档，深海占比应显著上升。
- M7 水面结论（自定义水地形不渲染）：本轮不新增任何水地形，结论不受影响。
- M8 河流命名/山麓带/雪线换肤：不动。

## 7. M2 气候接口预留（本轮不做，只留口）

设计基调 R3：气候先纬度后降水。本轮地基为 M2 预留的输入：

| 预留输入 | 数据 | M2 消费方式（未来） |
|---------|------|-------------------|
| 纬度 | 现成（y 坐标） | 温度带主决定（GenerateTerrainTypes 已在用） |

## 9. 已知粗糙处（初版诚实清单）

1. **边界类型按板块对全局一刀切**——同对板块边界全图同型；真实边界分段转变。v2 改"边界段 roll"（段长 6~12 格）。
2. **Voronoi 单归属**——没有板块混合/增生楔等过渡带，海岸线完全由抖动噪声雕塑。
3. **地盾/盆地只有海拔身份**——不产形态身份（不新增"地盾"形态类），盆地本轮未单独实现（裂谷兼作最低洼板内）。
4. **裂谷不做湖泊链**——东非大裂谷的串珠湖留给 M2 水文接管后补（接口即板内低海拔连通区）。
5. **火山只有数据标记**——不触发原版火山特征放置，灾害化归后续。
6. **x 回绕为矩形等距近似**——高纬板块实际面积偏大（等距投影畸变），极地强制海洋后影响有限。
7. **sea_level / world_age 用户配置项语义变化**——sea_level 失效（陆海比由板块配比决定），world_age 不再撒山。需在 Mod 说明中告知玩家。
8. **最大陆块拒绝循环取消**——泛大陆级板块允许占陆地 64% 以上（R2 设计基调：泛大陆级大块允许存在）；若实测出生点分布受影响，M2 阶段再评估"陆块数量下限"校正。

## 10. 验收对照（策划案 §8.4 摘 relevant 条）

- "山系沿板块边界或造山带分布" → 本轮后**从机制上保证**（此前是验收不过的项）。
- "河流追溯到山地/高地水源" → 山链成线后河流从链上发源，流域走向更可解释。
- "山口存在且不过密" → 主脊成链后，山口逻辑（后续 Layer3）有明确宿主。
- "每块大陆存在可进入大河流域" → 板内大片低地保证汇流空间。
