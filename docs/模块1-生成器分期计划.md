# 模块1 生成器分期计划

> 2026-10-01 所有者制定。替代旧版"三期"口径（已随工作流程.md 删除）。
> 每阶段交付=可运行的生成器增量 + 对应可视化/验收手段。

| 阶段 | 内容 | 输出 | 对应策划案章节 |
|------|------|------|--------------|
| S1 | 板块生成 + 板块视图 | 海陆板块格网（无河流山脉）；板块着色视图 | 1.1 因果链第1步 |
| S2 | 板块挤压/拉伸 | 边界造山、裂谷（海陆都有）；**Layer1 形态层全部定形**；矿物带（地质资源层） | 1.2 Layer1、4.2 地质资源层 |
| S3 | 气候 | 寒/温/热三带（温度=纬度+海拔） | 1.1 因果链第2步 |
| S4 | 水文 | 大河流域（水面格带）+ 小河（边缘属性） | 1.1 第4步、C类河流两卡 |
| S5 | 生物群系 | Layer2 地带覆盖 + 群系（气候+水文驱动） | 第3章 |
| S6 | 生物种类 | 各群系内资源/物种随机（生态资源层） | 第4-5章生态资源层 |

## 衔接注记

- S2"形成全部地形"= Layer1 形态层定形；Layer2 地带层在 S5 才叠加——与三层正交模型一致（形态与气候正交）。
- 矿物带（S2）= 策划案 4.2 地质资源层；生物种类（S6）= 生态资源层。两层分开正好落在两个阶段。
- 灾害标签（第7章）随各阶段顺带产出（火山=S2 消亡带、洪水=S4 河漫滩），不单列阶段。
- 微地貌（Layer3）多数在 S2/S4 顺带生成（山口/峡谷=S2、三角洲/河漫滩=S4）。
- 气象（风向/雨影/季风）按总案决策#12 后置第六部分，S3 降水仅用距海距离。
