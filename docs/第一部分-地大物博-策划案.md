## 0. 设计边界

- **本稿只设计自然环境**：地形、群系、资源、灾害、通道的生成规则与参数。
- **不覆盖**：单位移动力、建造者职业、城市空间、工作格、大区域、政体、总督、城市系统（建城判定）、原版文明适配。这些仅作为接口保留。

- **网络加成归口**：网络加成（区域建筑效果）归第二部分「千行百业」；本文仅输出其地理计算输入（区域聚合ID、地理评分，见第10章），不定义网络传播规则。
- **核心原则**：生成结果必须可解释、可可视化、AI可读；生成过程只做轻量因果，不做复杂地球物理模拟。

## 1. 地形生成

### 1.1 生成逻辑（轻量因果）

地形不是随机撒点，而是按以下因果链推导：

1. **板块骨架** → 决定大陆位置、海沟、岛弧、内海、海岸破碎度。
2. **气候带** → 温度由纬度与海拔决定；降水由距海距离决定（水汽自海岸向内陆递减）。山系雨影、季风等空间扰动**后置至「气象万千」模块**，本稿预留接口（占位预留，见第10章）。
3. **高程起伏** → 由造山带、侵蚀、沉积决定形态层（低地/隆起/山麓/山地/主脊）。
4. **水文网络** → 由海拔与降水决定河流、湖泊、三角洲、内流区。

### 1.2 三层正交模型

地形不再是平面清单，而是三个正交图层的叠加。每层只回答一个问题，避免"高程×起伏×气候"混排造成的判定空档与身份漂移。

```
Layer 1 形态层：这块地是什么形状？（只由海拔+起伏决定，与气候无关）
Layer 2 地带层：这块地被什么生态覆盖？（只由气候决定，叠加在形态之上）
Layer 3 微地貌层：这块地有什么局部特殊成因？（由位置/邻接关系决定，叠加标记）
```

**关键规则**：山地长什么由地带层决定（湿润山地=山地森林，干旱山地=裸岩），不由形态层自己规定。

#### Layer 1 形态层（海拔与起伏决定）

形态层只有 8 种，判定条件完备无空档：

| 形态 | 海拔条件 | 起伏条件 | 通行特征 |
|------|---------|---------|---------|
| 深海 | ≤-2000m | — | 远洋 |
| 浅海 | -2000~-200m | — | 大陆架 |
| 海岸/水面 | ≈0m（海陆交界或水体） | — | 海平面 |
| 低地 | <200m | 邻格高差<50m | 通畅 |
| 隆起（岗地/丘陵） | <200m | 邻格高差≥50m | 低地中的起伏处，仍属低层水系 |
| 山麓 | 200~500m | — | 山地前缘过渡带 |
| 山地 | 500~3500m | — | 高成本通行 |
| 主脊 | >3500m | — | 默认不可通行，山口例外 |

> 注：海拔阈值为默认值（对应1:4比例尺的观感），可在数值框架阶段整体缩放。

#### Layer 2 地带层（气候决定，叠加于形态层之上）

地带层决定低地/隆起/山麓/山地的生态覆盖与产出倾向。同一形态在不同地带下表现不同（湿润山地=森林，干旱山地=裸岩）。

| 地带 | 气候前提 | 典型形态宿主 | 生态特征 |
|------|---------|-------------|---------|
| 森林（雨林/季雨林/落叶林/针叶林） | 降水高—中 | 低地、隆起、山麓、山地 | 林业资源，木材产出 |
| 草原（热带/温带） | 降水中—低 | 低地、隆起 | 畜牧亲和 |
| 荒漠（热带/温带/寒漠） | 降水极低 | 低地、隆起、山麓 | 矿藏与特殊资源 |
| 苔原/冰原 | 寒带 | 低地、隆起 | 冻土资源 |
| 雪线/冰川 | 高海拔或极地 | 山地、主脊 | 永久冰体，水源储备 |
| 农耕开发区 | 人为改造（见3.4演替） | 低地、隆起 | 农业区，非自然生成 |

> 原"平原/草原/沙漠/冻土"的**产出参数差异保留在参数表（第2章B类地带卡）**中：地带层改变基础产出与资源亲和，形态层改变通行/防御/移动消耗。

> 命名对照：原"平原"没有被删除，而是**拆分为两个正交属性的组合**——低地/隆起（Layer1，管通行）× 草原/森林/农耕开发区（Layer2，管产出）。低地×草原≈原平原，低地×森林≈原平地树林。原词"平原"仅在起伏描述中保留为视觉语感（见1.3起伏表"平原感"）。

#### Layer 3 微地貌层（局部成因，叠加标记）

微地貌是"位置/邻接/事件"造成的局部特殊性状，不单独构成地形，而是叠加在 Layer1×Layer2 组合之上，多以地块属性或地貌标记实现。

| 微地貌 | 生成条件 | 叠加效果 |
|--------|---------|---------|
| 河漫滩（旧称冲积平原） | 低地/隆起 且 邻大河 | 粮+3，高洪水风险 |
| 三角洲 | 河口沉积带 | 粮+3金+1，极高洪水+风暴潮风险 |
| 沼泽/湿地 | 低地 且 排水不畅（邻水多/蒸发弱） | 通行天险，防御+4，排水后肥沃 |
| 峡谷 | 高差突变带（≥3级差相邻水道） | 最强 chokepoint，通道 |
| 绿洲 | 荒漠 且 有水源（地下水/内流河） | 荒漠中唯一淡水可用点（定居判断归城市系统） |
| 火山 | 消亡带/热点 | 肥沃+喷发风险双生 |
| 山口 | 主脊/山地中的低海拔缺口 | 通道标记，战略价值极高 |
| 瀑布/急流 | 河道+高程突变 | 航运阻断，水电潜力（模块2接口） |
| 浅滩/渡口 | 河流/海岸的浅水段 | 渡河点，登陆点 |

> 原"河流"不作为地形：小河为地块边缘属性（原版机制），大河下游为可航行水域（形态层=海岸/水面 + 河流等级属性），详见第2章C类与接口契约。

#### 各类别设立理由（设计记录 2026-09-28）

**Layer 1 形态层——为什么是这 8 种**

| 形态 | 设立理由 |
|------|---------|
| 深海/浅海（分界-2000m） | 原版只有"海洋/海岸"两档，表达不了"远洋 vs 大陆架"的差异。分界取大陆坡折线：浅海才有水产与石油架，深海是纯粹的航线空间——海军活动与资源分布因此有了层次。 |
| 海岸/水面 | 海陆交界与**大河可航行段共用同一形态**，这是"大河宽一格以上、海军商船可通行"的实现路径：亚马逊下游=水面形态+河流等级属性，不新增地形类型，原版渲染与寻路直接复用。 |
| 低地 | 承载文明主体的形态（农业、城市、密集道路）。对应原版"平原"的平坦部分，但不携带产出身份——产出来自地带。 |
| 隆起（岗地/丘陵） | 保留原版"丘陵"的通行/防御含义，但降维为纯形状：只表示"低地中的起伏处"，仍属低层水系（河流照样穿流），产出交给地带。原版"丘陵产矿"的设定由"隆起×荒漠/山麓地带"的组合复现。 |
| 山麓 | 原版完全缺失的过渡带。现实中山麓扇是聚落、绿洲链、山口所在（天山北麓、喜马拉雅南麓、山前城市带）。独立成类让"山脚文明带"这一地理事实可生成、可表达。 |
| 山地 | 高成本通行的主体，可改造（梯田、隧道、关隘），是"山区文明"（安第斯、埃塞高原）的空间载体。 |
| 主脊 | 默认不可通行的天险，仅山口（Layer3）可改写。原版山脉=纯墙，导致山地边缘只是绕行题；主脊+山口的组合让"连绵群山但有隘口"成为可玩的战略结构。 |
| 分界值依据 | 200m=地貌学平原/山地常用界线；500m≈中国地形阶梯分界；3500m≈中纬度雪线均值（雪线随纬度变化，精确值归气象模块）。阈值为1:4下的观感默认值，数值框架阶段可整体缩放。 |

**Layer 2 地带层——为什么是这 6 种**

| 地带 | 设立理由 |
|------|---------|
| 森林/草原/荒漠 | 降水连续谱的离散化（高—中/中—低/极低），覆盖地球陆地生态主体。三档是"产出与亲和有质变差异"的最小划分；再细（雨林/落叶林/针叶林）交给第3章群系，地带管粗、群系管细，避免同一信息两层各说一遍。 |
| 苔原/冰原 | 低温限树带。与荒漠共享"低产+特殊资源"的角色但成因不同（冷 vs 旱），对资源亲和和灾害标签的差异足以独立成类。 |
| 雪线/冰川 | 唯一由海拔而非纬度主导的地带，专治"冰川三重身份"混乱：它是地带层对山地/主脊的覆盖（乞力马扎罗、阿尔卑斯、青藏高原），形态归类不变。 |
| 农耕开发区 | 非自然生成，是3.4演替的产物。列入地带层是为了让"人类改造地表"用同一套图层语言表达（改造=换地带，不动形态）。 |

**Layer 3 微地貌层——为什么是这 9 种**

设立标准：只对"位置/邻接/事件造成、且改变通行或产出或风险"的性状设标记；气候造成的归地带，形状造成的归形态，Layer3 只收前两层装不下的"第三因"。

| 微地貌 | 设立理由 |
|--------|---------|
| 河漫滩 | 大河邻格的周期性泛滥沃土。原版"冲积平原"只是贴图词；这里它是机制：粮+3与洪水风险双生，模拟"尼罗河悖论"——最肥的地最危险。 |
| 三角洲 | 河口沉积的额外维度：金产出（航运/港口）+风暴潮风险。与河漫滩同源于沉积但风险类型不同（河洪 vs 海潮）。 |
| 沼泽/湿地 | 排水不畅的低地。通行天险+防御加成，排水后转沃土——给"围海造田/排干沼泽"式改造留接口（改造见3.4）。 |
| 绿洲 | 荒漠中唯一淡水可用点（定居判断归城市系统）。锚定丝路式城市链；没有它，细化后的荒漠只是大面积无意义空格。 |
| 火山 | 肥沃+喷发风险双生，长期地质事件源（灾害章接口）。 |
| 峡谷/山口 | 同为"高差突变处的通道"：峡谷是河流切割的 chokepoint，山口是翻山唯一缺口。二者让"隘口争夺战"成为可能，是主脊/山地不可通行规则的必要泄压阀。 |
| 瀑布/急流 | 航运阻断点：让"河流分级"有实际后果（上游船走不到），同时留水电潜力接口给模块2。 |
| 浅滩/渡口 | 渡河点。细化后河流处处是天堑，单位将无路可走；渡口把"渡河"从每格属性变成**地点**——渡河争夺才有意义。 |

**河流拆分的理由**：小河不值得占形态格（成本最低的做法是保留原版"地块边缘属性"机制，零新增渲染）；大河下游要通航就必须是水面——所以"小河=边缘属性，大河=水面形态+河流等级"，一格以上的河口宽度由此自然成立。

### 1.3 海拔体系（地块属性 + 派生量）

**海拔是每格的基础地块属性**（连续数值，单位米，随存档持久化），不是离散等级。后续「气象万千」模块的气温递减、雪线修正等均直接读取海拔计算。

**使用规则**：生成计算（水流方向、坡度、未来的气温递减/雪线修正）一律读连续数值；规则查找（形态判定、AI 决策、地图模式显示）一律走派生等级——两套口径不混用，等级只是数值的查表视图。

由高程属性派生出两个量：

- **高程等级**：海拔按区间映射为 -2~6+ 的离散等级，供形态层判定与地图模式显示使用；
- **起伏**：相邻格海拔差，决定隆起判定与通行/视觉表现。

#### 高程等级（海拔→等级的派生映射）

| 等级 | 海拔区间 | 形态层归类 | 说明 |
|-----|---------|-----------|------|
| -2 | ≤-2000m | 深海 | 远洋 |
| -1 | -2000~-200m | 浅海 | 大陆架 |
| 0 | ≈0m（水域） | 海岸/水面 | 海平面；大河可航行段亦为此层 |
| 1 | <200m | 低地 | 含低起伏处；高差≥50m 时表现为隆起 |
| 2 | 200~500m | 山麓 | 中山地前缘 |
| 3 | 500~1500m | 山地（低段） | |
| 4 | 1500~2500m | 山地（中段） | 峡谷/山口为Layer3通道标记，在此海拔带叠加于山地形态 |
| 5 | 2500~3500m | 山地（高段） | |
| 6 | >3500m | 主脊 | 极高，默认不可通行 |

> 注1：等级是显示与判定的派生层，底层存储始终是连续海拔。1:4比例尺下，相邻新格的海拔差通常在等级边界附近。
> 注2：原"5+雪原/6+冰川"**不再是形态归类**——雪原/冰川是 Layer2"雪线/冰川"地带对高海拔形态（山地/主脊）的覆盖：海拔超过雪线（随纬度降低，赤道约5000m、极地海平面）的形态格，地带层强制为雪线/冰川，形态层归类不变。

#### 起伏程度（相邻格海拔差）

| 相邻海拔差 | 起伏程度 | 视觉与通行表现 |
|-----------|---------|--------------|
| <50m | 极平缓 | 平原感，无通行障碍 |
| 50—150m | 平缓—轻起伏 | 轻微起伏，不影响通行 |
| 150—400m | 中等起伏 | 丘陵感（隆起判定线），阻遏通行 |
| 400—800m | 强起伏 | 山地感，天险通行 |
| ≥800m | 极陡 | 断崖/主脊感，不可通行；峡谷候选 |

#### 水流方向

水流永远从海拔高的格子流向海拔低的相邻格子，沿最陡下降方向。若四周海拔均不低于自身，则形成内流湖。河流宽度与流速由流域集水面积与坡度（海拔变化率）共同决定。

### 2.1 参数说明

| 叠加修正 | 通行改写：天险（无渡口/浅滩时移动3，渡河；可航行段水面移动1）；防御+2（守河方）/攻击-3（攻河方）；堵塞（天然防线） |
| 灾害风险 | 洪水 |
| 资源亲和 | 水产类、贸易类（航运） |
| 淡水可用性 | 可用 |
| 特殊属性 | 可航行（第二部分接口）；下游两岸生成河漫滩/三角洲标记。实现注记：陆军进入大河水面段=泅渡/浮桥状态（"在水上"减力）叠加渡河惩罚-3 |

### 2.3 参数取值理由（设计记录 2026-09-28）

**总体数值原则**（对应总案决策#8 自建数值体系）：

1. **离散梯度**：移动消耗 1/2/3/∞ 与原版语义同构（原版森林/丘陵=2），第二部分做单位换算时不换思维。
2. **防御占优**：任何地形守方加力 ≥ 攻方减成的绝对值（如山地 +5/-3）——符合"攻山难"的直觉，也给"以地形防守"策略存在空间。
3. **加力上限 +7**：全表唯一，只给峡谷——保证"最强要塞"只有一个候选，战略价值可预期。
4. **全部数值为"默认倾向"**：数值框架阶段统一调参，本轮只定结构、梯度方向和相对量级。
5. **卡片加力=高差零基准**：A/C类卡片的攻防加力视为"攻守双方相对海拔差=0 时"的地形基础值；相对高差修正（高打低/低打高）与射程规则归第三部分「合纵连横」设计，模块1只保证海拔（契约字段）与遮蔽等级（契约字段）两个输入完备。

**A类形态卡的取值逻辑**

- **移动消耗阶梯** 低地1→隆起2→山麓2→山地3→主脊∞：前两级差距在"是否影响行军节奏"，后两级差距在"是否值得翻山"。山麓与隆起同为2，因为它虽是山地前缘，但坡度平缓（扇形地），行军成本与丘陵同级；它的防御值低于山地（+2 vs +5），体现"居高临下但仍有回旋空间"。
- **隆起 防御+3/-1、远程+2**：+3 直接锚定原版"丘陵防御+3"的玩家直觉；远程+2 是"高地优势"的最小值。
- **山地 控制区=是**：山地天然分割战场（无法绕行的大部队只能走山口），这是"堵塞"参数存在的唯一理由。
- **海岸/水面 登陆3、反登陆+2/-2**：把"登陆战"做成独立场景（诺曼底式），海军强但上岸弱，与"大河天险"共用数值。
- **主脊不设攻防值**：不可进入的地形持有攻防值是死代码；它的战略意义由"堵塞=绝对屏障"+ 山口卡共同表达。
- **资源亲和只挂地质/水文类**：形态卡只持"形状决定"的资源（隆起挂矿业林业、浅海挂水产石油），生态类资源全部在地带卡——参数归属与成因一致。

**B类地带卡的取值逻辑**

- **产出数值刻意拉平**（森林粮+1锤+1、草原粮+1锤+1、荒漠/苔原锤+1）：地带层的价值差异主要体现在**资源亲和与灾害**上，基础产出只给方向性倾向；否则地带会压过形态+微地貌成为唯一决策变量，三层正交就退化成一层。注意：这是概念稿阶段的占位倾向值（v1.4 重构时合并旧卡取了保守中间值），**具体数值留待数值框架阶段统一评审**。
- **农耕开发区 粮+2**：全表最高基础产出，但受土壤等级 S0—S3 修正——肥沃冲积土上的农田 vs 贫瘠坡地的农田差距由土壤表达，不由地带重复表达。
- **雪线/冰川 无产出**：永久冰体不提供产出，价值在水源储备与战略屏障；这也让"青藏高原式高寒"成为真实的约束而非贴图。

**C类叠加卡的取值逻辑**

- **河漫滩/三角洲 粮+3**：全表最高肥力，必须配上防御负值（-1/-2）——"最肥的地最危险"是本 Mod 水文设计的第一原则。
- **沼泽 防御+4/-5、远程+4、通行天险**：全表防守效率最高的地形，但粮+1 低产——守得住、养不活，历史上沼泽文明（排水造田）的动机由此产生。
- **峡谷 +7 与山口 +5 的分工**：峡谷是中山地走廊的中段要塞（两侧高地压制，远程+5），山口是翻山唯一钥匙（通行改写覆盖主脊的不可通行）。两者都是 chokepoint，但峡谷"守走廊"、山口"开锁"。
- **瀑布/急流 纯功能标记**：不加任何产出/攻防，只做航运阻断——河流分级因此有后果（上游船到不了，资源要陆路转运）。
- **河流两卡的分工**：小河保留原版"地块边缘属性"机制（零新增渲染成本），数值沿用"守河+2/攻河-3"的天然防线；大河是水面形态+等级，可航行段移动1、无渡口时渡河移动3——"海军进大河、陆军绕渡口"由此成立。

## 3.4 群系演替（地形改造后）

### 核心原则

- **气候与降水不变**：改造只改变地表覆盖，不改变底层气候与降水条件。
- **砍掉雨林不会直接变草原**：热带高降水区砍掉雨林后，次生林或灌木地会快速再生；只有持续人类干预才会向农业区或退化群系演替。
- **演替需要时间**：自然演替是缓慢的；人类加速改造可缩短时间但有代价。

### 演替类型

| 类型 | 触发条件 | 时间尺度 | 结果 | 代价/风险 |
|------|---------|---------|------|----------|
| 自然恢复 | 停止人类干预 | 极长（数十年—数百年游戏回合） | 向原生群系恢复 | 无，但极慢 |
| 农业开垦 | 劳动者开垦 + 排水/灌溉 | 中（数回合—数十回合） | 农业开发区 | 失去原生资源，可能土壤侵蚀 |
| 过度开发 | 长期高强度利用 | 长 | 群系退化 | 土壤贫瘠化、荒漠化、资源枯竭 |
| 排水改造 | 沼泽/湿地排水 | 中 | 低地（沼泽标记移除，土壤肥沃） | 失去湿地资源，地面沉降风险 |
| 森林砍伐 | 砍伐林群系 | 短—中 | 次生林/灌木地/裸地 | 水土流失，若降水高则次生林再生快 |
| 火耕/烧荒 | 热带/亚热带森林 | 短 | 短期肥沃→长期退化 | 土壤养分快速流失 |
| 梯田改造 | 山地开垦 | 长 | 梯田农业区 | 高劳动投入，滑坡风险 |
| 灌溉扩展 | 干旱区引水 | 长 | 绿洲/灌区扩大 | 盐碱化、水源枯竭 |

### 主要群系演替路径

#### 森林类群系

|---------|---------|------------|------------|------------|

| 热带雨林 | 火耕 | 短期肥沃裸地 | 养分耗尽裸地 | 灌木地/稀树草原 |
| 季风雨林 | 砍伐 | 季风雨生林 | 季风农业区 | 次生林恢复 |
| 温带落叶林 | 砍伐 | 灌木地/次生林 | 温带农业区/牧场 | 落叶林恢复（中速） |
| 温带针叶林 | 砍伐 | 灌木地/裸岩 | 寒温带牧场 | 针叶林恢复（极慢） |

#### 草原类群系

| 原生群系 | 改造行为 | 结果 | 风险 |
|---------|---------|------|------|
| 热带草原 | 过度放牧 | 热带荒漠/裸地 | 荒漠化 |

| 湿地/沼泽 | 围垦 | 农田/水产养殖区 | 洪水风险转移、生态退化 |

#### 山地/山麓

| 原生群系 | 改造行为 | 结果 | 风险 |

### 关键规则

1. **降水决定演替天花板**：高降水区砍伐后必然向森林恢复，不会变成草原；低降水区砍伐后才可能退化为灌木或荒漠。
2. **土壤记忆**：原生群系的土壤类型（S0—S3）在改造后保留，影响改造后的产出上限。冲积沃土无论怎么改都仍是沃土；贫瘠土开垦后上限低。
3. **灾害标签变化**：部分改造会改变灾害风险。如沼泽排水后洪水风险降低但干旱风险增加；森林砍伐后滑坡风险增加。
4. **演替不可逆点**：部分退化超过临界点后无法自然恢复，需要主动治理（如植树、休耕、灌溉修复）。

### 3.5 设计理由（设计记录 2026-09-28）

**为什么需要群系层而不只用地带**：地带只有 6 种，回答"产出方向与亲和"；但玩家和 AI 认知的是"热带雨林""针叶林"这种具体生态。群系层是地带×气候细节的**表现层**——判定逻辑不独立维护，从 Layer1×Layer2+降水推导（见3.1），所以群系可以有很多个而不增加规则系统的复杂度。地带管粗、群系管细，信息只存一份。

**群系清单的取舍标准**：覆盖地球陆地生态主体即可，不为罕见生态单独立项（如地中海硬叶林并入温带落叶林的暖干变体，由生成时的降水亚型表达）。高山草甸是唯一按海拔而非纬度划界的群系（树线以上任何纬度），因为高海拔生态在细化地图上面积可观且战略意义特殊（牧场、山口通道）。冰川/冰盖不列为群系——它是"雪线/冰川"地带对形态的覆盖（见1.2注2），避免三重身份。

**为什么是矩阵而不是清单**：3.3 矩阵把"某群系能长在什么形状上"变成一张可查的表（●○—三值）。原版没有这种结构，导致"森林该长在山上还是平原"全靠硬编码散点；矩阵让生成器、AI、图例三处共用同一份事实。

**演替系统的设计动机**：原版地形改造是"建造者点一下、地块瞬变、零后果"。本 Mod 的愿景是"文明发展模拟器"，所以改造必须有**记忆、代价、时间**三个维度：土壤记忆（S0—S3 跨改造保留）是记忆；失去原生资源/侵蚀/荒漠化是代价；演替时间尺度是时间。同时演替解释了 B 类"农耕开发区"地带的来源（非自然生成=演替终点），两层互为闭环。改造行为本身（谁动手、花多少锤）归第二部分，本文只定义改造的自然后果规则。

### 4.2 生成逻辑

资源不从天上撒，而从两类图层推导：

**地质资源层**：由板块边界、造山带、火山弧、沉积盆地、古老地盾决定。战略资源、矿业类、部分文化类（宝石、黄金）主要在此层。

**生态资源层**：由群系、水文、过渡带决定。农业类、畜牧类、林业类、水产类、贸易类主要在此层。

### 4.3 已确认原则

- 所有资源都有用，反对奢侈品独大。
- 同环境多资源：草原可有牛/羊/马，森林可有木本资源与动物，山地可有矿与野生动物。
- 关键资源多源但不均匀：每局至少 2—4 个不相邻来源区；奢侈类更分散，战略矿类更偏地质带。
- 资源簇半径：3—8新格；同簇可有主资源 + 伴生资源。

### 5.3 设计理由（设计记录 2026-09-28）

**为什么按产出细分而不是沿用原版"加成/奢侈"二分**：原版的问题不是分类本身，而是奢侈品独大——贸易价值高、唯一给宜居，导致"抢奢饰品"成为资源玩法的全部。本设计把"高贸易价值+宜居"保留为**贸易类**（香料/丝绸/茶叶/咖啡/瓷器等），但让它与其他七类同表竞争地块：农业管粮、战略管工业、文化管科文——资源与经济系统全面对接，贸易类只是价值维度之一而非终点。"所有资源都有用"因此从口号变成表格结构。

**两层生成逻辑的理由**：地质层（造山带/火山弧/沉积盆地/地盾）产出不可再生、位置永恒（铁、石油、宝石）；生态层（群系/水文）产出可再生、随演替变化（农畜林水产）。两层分开，"科威特的石油"和"乌克兰的麦田"才不会用同一套撒点逻辑——资源分布因此可解释，也直接服务 AI 的扩张评分。

**三列亲和的分工对应三层模型**：地质亲和（含"形态："标注）、群系亲和（只填 Layer2）、生成条件（Layer3/水域/气象占位）——一张资源表横向走完三层模型，与第 2 章的参数卡口径一致，避免"丘陵亲和"这类跨层混排（审查A修复点）。

**三个为后续模块埋伏笔的列**：易腐性（生鲜 vs 耐储→模块2贸易网络的运输半径与加工价值）、开采条件（地表/浅层/深层→时代门槛，服务"千行百业"的生产系统）、贸易标签（已注明归模块2网络加成计算的输入）。

**资源产出种类与数值的确定逻辑**（当前为概念稿量级，精确平衡归数值框架阶段）：

1. **产出种类=资源的经济性格**：与该资源在4.1中的产出方向细分一一对应——粮=食物型、锤=工业原料型、金=贸易型、科/文/信仰=文化型、宜居=贸易类专属（承接原版奢侈品的宜居职能）。一种资源原则上只给 1—3 种产出，不造"六边形战士"。
2. **数值的第一条锚线：原版同类资源的相对排序**。黄金>白银、鲸>鱼、香料≈丝绸≈茶叶 这些原版既有的量级关系保持，降低玩家学习成本（总案决策#8：参考官方但不拘泥）。
3. **数值的第二条锚线：地带卡基础产出（粮+1锤+1）为基准**。资源加成控制在基础的 1—3 倍内；且按"资源簇"算账——细化后一簇占 3—8 新格，**簇总产出≈原版单个资源格的产出**，保证 1:4 细化不会导致总经济膨胀。这是与第 2 章 B 类产出拉平配套的同一本账。
4. **战略资源产出刻意压低**：铁锤+2、马锤+1——战略资源的价值在解锁单位与工业用途（战略标签列），不在地块产出，防止"战略格=万能高产格"挤掉经济分工。
5. **易腐性与金产出负相关**：鱼/贝/虾粮高金低（鲜货不值远钱，须加工或快运），珍珠/黄金金+3且易腐性低（耐储高值）——为模块2的加工与运输系统预设价值梯度。

## 6. 特殊地貌与自然通道

特殊地貌是生成结果中的“地标级地理”，它们不是独立地形，而是地形组合或极端表现。

### 6.1 自然通道

| 地貌 | 构成 | 战略意义 | 生成约束 |
|------|------|---------|---------|
| 山口 | 主脊 + 两侧山地/山麓（Layer3通道标记，见2.2C类） | 控制山脉走廊的唯一/少数通道 | 每段主脊至少1个，间距8—15新格 |
| 峡谷 | 深切河流 + 两侧高地（Layer3通道标记，见2.2C类） | 最强 chokepoint，一夫当关 | 大河切穿山系处生成 |
| 隘路 | 山麓 + 河流 + 狭窄平地 | 次强通道，可设关隘 | 河谷收窄处 |
| 草原走廊 | 草原/温带草原连续带 | 骑兵机动走廊，游牧通道 | 两山系间或山系与荒漠间 |
| 海岸通道 | 海岸平原连续带 | 海军与陆军协同走廊 | 破碎海岸或半岛链 |

### 6.2 特殊地貌

| 地貌 | 构成 | 特性 |
|------|------|------|
| 三角洲 | 大河 + 海岸 + 泥沙沉积 | 最肥沃、最高洪灾、最佳港口候选 |
| 河口湾 | 大河 + 陡峭海岸 | 深水港候选，无三角洲淤积 |
| 峡湾 | 冰川侵蚀 + 海岸 | 极深近岸，天然良港 |
| 绿洲 | 荒漠 + 地下水/泉 | 荒漠中唯一淡水可用点，商路节点 |
| 内流湖 | 内流区 + 蒸发盆地 | 盐湖或淡水湖，周边绿洲环 |
| 瀑布/急流 | 河流 + 高程突变 | 天然水电潜力（第二部分），航运阻断 |
| 浅滩 | 河流/海岸 + 泥沙堆积 | 渡河点、登陆点、航道障碍 |
| 火山 | 消亡带/热点 | 肥沃+灾害双生，地热与硫磺 |
| 冰川 | Layer2雪线/冰川地带覆盖的主脊/山地（见1.2） | 水源储备，后期融化影响海平面 |
| 冰缘/冻土裂隙 | 冻土区 | 淡水季节性可用性差，特殊资源 |

> 与2.2C类的分工：C类卡管**单格参数**（宿主条件+叠加修正），第6章管**区域级组合**（生成约束+战略意义）。山口/峡谷/瀑布等在两处都出现不是重复：改数值去2.2C类，改分布规则来第6章。单一微地貌不登记为特殊地貌（契约字段防双轨，见第10章）；隘路/草原走廊/海岸通道是连续地带级通道，无单格卡，走契约"通道潜力"字段。

## 7. 灾害与风险标签

### 7.1 灾害类型与来源

| 灾害 | 来源地形/群系 | 影响 | 备注 |
|------|--------------|------|------|
| 洪水 | 河漫滩、三角洲、沼泽、季风区（气象占位） | 摧毁/削弱改良、人口、建筑 | 洪水后肥力短期提升 |
| 火山喷发 | 火山、火山弧 | 摧毁周边、短期降温、长期肥沃 | 周期性，可预警 |
| 干旱 | 雨影区（气象占位）、大陆内部、荒漠边缘 | 农业减产、宜居下降、游牧压力 | 气候周期性 |
| 风暴/飓风 | 暖洋流低纬海岸、季风海岸（气象占位） | 海岸摧毁、海军损失、贸易中断 | 季节性 |
| 暴雪/寒潮 | 高纬、内陆寒带、无山阻挡冷空气通道 | 移动力下降、农业停滞、人口损失 | 冬季 |
| 地震 | 板块边界、消亡带、转换断层 | 随机摧毁建筑、山崩、海啸触发 | 难预警 |
| 海平面上升 | 低洼海岸、三角洲、珊瑚环礁 | 永久淹没、海岸后退 | 后期气候机制 |
| 泥石流/滑坡 | 多雨山地、山麓、火山 | 阻断通道、摧毁改良 | 暴雨或地震后 |
| 沙尘暴 | 荒漠边缘、干旱草原 | 移动力下降、农业损失、远程惩罚 | 季节性 |

> 注：标注"气象占位"的来源（季风区、雨影区、季风海岸）为占位预留输入，实质计算归「气象万千」模块（见第10章契约）。

### 7.2 设计原则

- 灾害不是纯惩罚，而是**高价值地理的代价**。
- 肥沃冲积平原必须带洪水风险；火山沃土必须带喷发风险。
- 灾害标签必须可视化，玩家能在建城/扩张前读到。
- 灾害频率与强度归后续系统，本稿只保证标签因果一致。

## 8. 轻量校正与验收

### 8.1 校正目标

只保证四件事：

1. 每块大陆有可进入的大河流域。
2. 每条关键山系有可通行山口。
3. 关键资源非垄断，多源存在。
4. 每局至少存在若干高价值 but 高风险的地理：大河洪泛区、火山沃土、海峡 chokepoint、山口要道。

### 8.2 允许操作

- 在山系中增删少量山口。
- 调整支流汇入，保证大河可达海岸或湖泊。
- 为关键资源增加/减少来源区，使其符合多源规则。
- 微调海岸，形成海峡、半岛、岛链。

### 8.3 禁止操作

- 禁止为了让某个文明强而移动其出生点附近的山/河/资源。
- 禁止在不符合气候/地质逻辑的位置硬塞资源。
- 禁止把河流改成单纯服务某文明的形状。
- 禁止为了对称而破坏大陆与山系的自然感。

### 8.4 验收标准

一张合格地图必须满足：

- 河流都能追溯到山地/高地水源，并最终入海、入湖或明确内流。
- 山系沿板块边界或造山带分布，山口存在且不过密。
- 河漫滩挨着河流，不靠随机刷肥沃。
- 资源符合地质/气候/群系逻辑，且关键资源不多源垄断。
- 每块大陆存在可进入大河流域与至少一个战略通道。
- AI能根据地理评分选出合理扩张方向。
- 玩家能通过地图模式解释“为什么这里肥沃/多矿/危险/是通道”。

## 9. 地图可视化与图例

### 9.1 必备地图模式

| 模式 | 显示内容 |
|------|---------|
| 标准地形 | 形态层、地带层、海拔、起伏程度 |
| 水文模式 | 流域、河流等级、洪水风险 |
| 气候模式 | 温度、降水（季风、雨影：占位预留，归「气象万千」） |
| 群系模式 | 生物群系、土壤等级 |
| 地质模式 | 造山带、沉积盆地、地盾、火山弧 |
| 资源模式 | 资源簇、来源区、伴生资源、品质 |
| 灾害模式 | 各类灾害风险等级 |
| 通道模式 | 山口、河谷、海峡、草原走廊 |

### 9.2 图例规则

- 山口：V型缺口图标，标注海拔/通道属性。
- 主脊：锯齿连续线，不可通行。
- 河漫滩：浅蓝色阴影，标注洪水概率。
- 三角洲：扇形图标，标注泥沙来源河。
- 资源簇：同心圆，外圈标注伴生资源。
- 火山：三角图标，标注活跃/休眠状态。
- 海峡/隘路：收缩线图标，标注控制价值。

### 9.3 提示原则

任何复杂标签都要能一键解释来源。例如：
- 鼠标悬停“肥沃” → 显示“河漫滩，源自XX河，最近一次洪水XX回合前”。
- 鼠标悬停“多矿” → 显示“造山带，铜/铁伴生，富集级”。
