# M9 东亚真实地图 · 学习笔记

> 里程碑 M9（2026-10）——真实东亚静态图（`mod/Maps/RR_EastAsia.lua`），
> 作为 RR_Tectonics 生成器的 **ground truth 教材**。本文按区域逐条记录
> "真实地图教给生成器的规则"，供后续校准参数（对照 `docs/M1-板块地壳生成-设计.md` §8）。
> 数据统计口径：120x78 网格离线仿真（与脚本同阈值），经度 70°E~145°E、
> 纬度 10°N~55°N。

## 0. 数据来源与精度（诚实标注）

| 项 | 值 |
|---|---|
| 数据源 | AWS Open Data **Terrain Tiles**（Mapzen/Tilezen）z5 Web-Mercator GeoTIFF 瓦片，42 块（x22-28, y10-15） |
| 数据合成 | 陆地 **SRTM** + 海底/补洞 **ETOPO1**（NOAA）融合，int16 米 |
| 网格 | 0.625° x 0.577°（= MAPSIZE_RR_STD10 的 120x78，格心双线性重采样） |
| 量化 | 20m 步进（值域 -8000~+8800m，base-90 双字符编码，回读零误差） |
| 精度限制 | 格内**平均海拔**——0.6° 格把峡谷填平、把 6000m 峰均值化；喜马拉雅格均 5500m 而非 8000m；日本海沟最深格 -1508m（真实 -8000m，沟宽不足一格） |
| 抓取工具 | `tools/fetch_eastasia_dem.py`（瓦片缓存 `tools/.dem_cache`，已 gitignore） |

气候地带**不是** DEM 派生，是编纂格网（同工具生成）：纬度基线 + 雨影荒漠
多边形（塔克拉玛干/戈壁/卡拉库姆/塔尔/柴达木）+ 海拔雪线（≥3000m 高山苔原、
≥4600m 高山雪）+ 季风区边界（约 105°E 东亚季风西界、恒河平原例外）。
取值依据 Koeppen 分布常识，未逐站校验，属"教学级"精度。

## 1. 地块类型：海拔阈值必须叠加局部起伏（最重要的一条）

真实 DEM 直接暴露 RR 纯海拔门槛（≥700m 即山地）的系统性错误：

| 区域 | 格均海拔 | 真实地貌 | 纯海拔门槛判据 | 正确判据 |
|---|---|---|---|---|
| 塔里木盆地 | 1000m | 平坦沙漠盆地 | ❌ 整片山地 | 高而平 → 丘陵/平地 |
| 蒙古高原 | 1200-1600m | 平缓草原台地 | ❌ 山地 | 丘陵 |
| 云贵高原 | 1800-2200m | 喀斯特高原面 | ❌ 山地 | 丘陵（缘部才山地） |
| 青藏高原 | 4500-5000m | 宽谷高原 | （≥2800 无条件山地——本图采信） | 主脊/山地（雪线） |
| 喜马拉雅/天山/昆仑 | 4000-5500m | 真山脉 | 山地（侥幸对） | 山地 |

**规则 R1（教给 RR_Tectonics）**：`地块类型 = f(海拔, 局部起伏)`，不能是
`f(海拔)`。本图落地：`≥2800m 无条件山地`（雪线高原与真山脉在此汇合）；
`700-2800m 段 5x5 邻域起伏 ≥600m 才是山，否则丘陵`（台地面）；`200-700m 丘陵`；
`<200m 平地`。仿真结果：山占陆地 48%（真实东亚就是多山，见 §7 讨论）。

## 2. 形态层与"隆起"判据

- 真实 DEM 下平原格间高差普遍 <20m（华北平原 5-50m 波动）——**50m 隆起门槛
  会把整片平原刷成"隆起"**（这正是任务2 把它提到 100m 的实证；真实图上即使
  100m 也只该出现在台缘/谷坡）。
- 真实地图的低地+隆起仅占陆地 **20.1%**（低地 370 / 隆起 891 / 山麓 2001 格），
  与 RR_Tectonics R4 指标"低地+隆起 ≥70%"差距巨大。
  **规则 R2**：70% 低地目标是"程序化大陆的游戏性配比"，不是真实地理；
  若生成器要拟真，低地占比应显著下调，或承认真实大陆"山麓丘陵带"才是主体过渡带。
- **规则 R3**：山麓带（200-700m）在真实地图上极宽（云贵、黄土、蒙古台地），
  是高原→平原的真正过渡形态，不是山体旁的一格裙边。

## 3. 气候地带：纬度基线 + 雨影 + 雪线的三层结构

仿真分布：森林 5581 / 草原 1528 / 荒漠 614 / 泰加 840 / 高山苔原 412 / 高山雪 385。

- **规则 R4（雨影荒漠）**：塔克拉玛干距喜马拉雅-昆仑雨影源约 **3-5 格（2-3°）**，
  不是贴着山麓的——雨影荒漠与山脉之间隔着天山北坡草原带。生成器若做雨影，
  荒漠中心应在山链背风侧 200-600km，而非贴山。
- **规则 R5（季风西界）**：东亚森林带的西界约 105°E（= 青藏高原东缘+大兴安岭），
  与地形界线而非纯纬度重合——季风边界跟着山走。
- **规则 R6（雪线）**：常绿雪原从 ≥4600m 开始（喜马拉雅/喀喇昆仑），
  3000-4600m 是高山苔原（青藏高原面）；纯纬度雪线在本图纬度范围内（≤55°N）不出现。
- **规则 R7（草原带位置）**：欧亚草原（steppe）夹在荒漠与泰加之间，
  纬度 46-51°N + 内陆（蒙古高原），不在沿海。

## 4. 河流：真实河系教给分级逻辑的规则

30 条折线（12 条专名 + 18 条支流/次级）已按真实走线编纂并栅格化。
叠加目验图：`docs/reviews/M9-eastasia-rivers.png`。

- **规则 R8（大河必穿高原出峡谷）**：长江/黄河/湄公河/萨尔温/伊洛瓦底
  全部发源于青藏高原东缘（≥2800m 主脊区），先穿高山（= 本图自动标急流，
  RR 分级 ≥300m 段保持边缘河）再入平原转水面。源头高地→下游低地的高差
  是分级逻辑的天然驱动。
- **规则 R9（河网密度对比）**：季风区河网极密（长江 5 条一级支流在
  15°E 跨度内并列入海），干旱区只有内流河（塔里木、伊犁、阿姆）——
  **河网密度是降水格局的一阶表达**，生成器可用"距最近常年河格数"反推湿度。
- **规则 R10（内流河是正常类）**：塔里木/伊犁/阿姆河不出海，真实存在；
  RR 分级把"内流→保持边缘河、不配名"的现成行为恰好正确，无需改。
- **规则 R11（三角洲在侵蚀海岸是单口、在堆积海岸是扇形分流）**：
  长江单口、黄河单口（现行河道）、恒河-布拉马普特拉合流扇（两条折线
  在 (90,23) 汇合后共用一个出海口）——并流点一格内共享河沿即可自然表达。
- **规则 R12（DEM 海岸量化误差）**：真实河口距 0.6° 水格 1-3 格，
  必须有"河口延拓"（BFS 接到最近邻水格）否则分级判"内流"错失大河。
  本图已在栅格化器内置。

## 5. 海洋：真实海陆过渡的三级宽度

- 深海（≤-800m）离岸普遍 **3-6 格**：日本海沟一格 -1508m 直接贴日本东岸
  （真实海沟特征：陡），中国东海外陆架平缓（-100~-800 浅海带宽 4-6 格）。
- **规则 R13**：深海→浅海→海岸的带宽是**板块边界类型**的函数：
  俯冲带（日本）窄而陡，被动陆缘（中国东海）宽而缓。
  RR_Tectonics 的 RR_TEC_SHELF_RINGS 固定 3 环，应向"消亡边界窄陆架、
  板内宽陆架"分化。

## 7. 遗留粗糙处（诚实清单）

1. **山地占比 48% 偏高**：双判据已救回台地，但 0.6° 格均海拔仍把大面积
   崎岖区（横断山、秦岭、南岭、喀尔巴阡式褶皱区）整体推成山。可玩面积
   集中在华北/长江/恒河/日本沿岸。若实机观感太" mountain soup"，
   调 `RR_EA_PLOT_MOUNTAIN_MIN_RELIEF`（600→800）或 700 门槛提到 900。
2. **青藏高原整片主脊（853 格）**：≥2800m 无条件山地使高原面不可通行，
   符合"世界屋脊"设定但压缩了西域玩法；雪线主脊具名卡会大片铺白。
3. **气候格网是编纂值**：季风西界 105°E、荒漠多边形边界都是手绘的，
   柴达木/河西走廊等过渡带只给了一档分类。
4. **河流折线是 0.6° 手描**：黄河"几"字弯、长江荆江段在 2-3 格内被迫取直；
   恒河-布拉马普特拉三角洲的汊流只画了一支；印度河三角洲在图外（西界 70°E 截断）。
5. **河沿流向是角邻格海拔启发式**：未做原版 DoRiver 的连续流走查，
   汇流角偶发"两河对顶"渲染小疵（功能无碍，IsRiver 连通性不受影响）。
6. **原版 AddRivers 补充支流**：走"山>丘>平>水"伪高程，在真实地形上
   近似合理但会在干旱区（塔里木边缘）画出违背气候的小河——暂未按气候带屏蔽。
7. **无湖泊**：青海湖、巴尔喀什湖未落格（AddLakes 未调用 + 孤儿湖回填逻辑会
   填平无河小湖）；咸海仅以阿姆河终点暗示。
8. **南北两缘截断**：55°N 切过南西伯利亚（鄂毕河流域只露源头）、
   10°N 切过湄公河/红河三角洲（河口延拓到图边为止）。
